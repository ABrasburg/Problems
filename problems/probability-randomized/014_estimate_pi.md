# 014 - Estimate Pi

## Resumen

Estimar el valor de pi usando puntos generados aleatoriamente.

## Idea

Se generan puntos dentro de un cuadrado que contiene un cuarto de circulo. La proporcion de puntos que caen dentro del circulo aproxima el area relativa; multiplicando por cuatro se obtiene una estimacion de pi.

## Complejidad

- Tiempo: `O(n)` para `n` muestras.
- Espacio: `O(1)`.
